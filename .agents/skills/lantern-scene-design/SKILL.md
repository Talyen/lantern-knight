# Lantern scene design

Read [scene design](../../../docs/scene-design.md) and the project's artwork instructions before composing. The registry, scene parser and renderer enforce construction. Missing artwork needs a coherent new source, not geometry or clipping improvisation.

Use the production scene preview and the [contributing verification workflow](../../../CONTRIBUTING.md#verification). Inspect requested captures directly, preserve source artwork, and complete required asset finalization. Report exact verification boundaries without treating structural checks as visual acceptance.
