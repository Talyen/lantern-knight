# Scene fragments

The Scene Library saves reusable artwork arrangements here as small JSON recipes. A version 1 recipe contains a name and scene objects, including their transforms, attachments and light fixtures. Inserting a fragment creates independent copies with new object and fixture identities.

Gameplay placements, paths and room geometry remain in the scene document. Generated thumbnails and captures stay outside Git.

See the [scene editor](../../docs/developer-tools.md#scene-editor) for creation and reuse.
